**Financial Guardian** is a personal finance dashboard and budgeting application designed to help users track capital flows, manage budgets, and oversee investments securely.

> [!WARNING]
> This repository is currently a placeholder. If you are looking for the active development logs or codebase of the personal finance tracking dashboard, it is currently hosted inside the **[`hand-written-regonizer-ai`](https://github.com/Lakshana-2007/hand-written-regonizer-ai)** repository.
> 
> To align this repository with your active project code, you can rename `hand-written-regonizer-ai` to `financial-guardian` in your GitHub Settings, or migrate the source files here.

---

## 🧭 Planned System Modules

Once code is migrated or initialized, the project will feature:
* **Expense & Income Ledger:** Dynamic CRUD operations with category tagging.
* **Budget Allocator:** Set limits on specific categories (e.g. food, rent, entertainment) and receive overreach alerts.
* **Financial Analytics:** Visualization of trends and savings ratios using responsive charts.
* **Recurring Subscriptions Tracker:** Keep tabs on recurring monthly billing cycles.

---

## 🛠️ Proposed Tech Architecture

* **UI Framework:** React with Vite & TypeScript
* **Styling:** Tailwind CSS & Shadcn/UI
* **State Management:** React Query & Local Storage sync
* **Design Guidelines:** Mobile-responsive dashboards with dark/light themes.

## 📜 How to Migrate Active Code Here
To move the active personal finance code from the other repository into this one:
1. Clone this repository locally.
2. Copy files from the `hand-written-regonizer-ai` folder (excluding the `.git` directory) and paste them here.
3. Commit and run:
   ```bash
   git add .
   git commit -m "feat: migrate active FinanceTracker codebase"
   git push origin main
   ```
